# Evaluation QA Set

`qa_set.json` is the version-controlled artifact location, not a populated benchmark. It is still empty because this repository has no independently reviewed, indexed source corpus and hand-labeled questions. Do not report retrieval quality or RAGAS scores from synthetic tests as production results.

Each case must have a stable `id`, a specific `question`, `answerable`, and a source-grounded `reference_answer`. Answerable cases require one or more `relevant_source_ids` resolving to the exact stable identifiers used by retrieval. Unanswerable cases must use an explicit abstention reference and an empty source-ID list. `evaluate_dataset` applies RAGAS answer-quality metrics only to answerable cases; it separately reports retrieval-empty and explicit-abstention rates for out-of-corpus cases. Increment `dataset_version` when labels change and set `source_corpus_version` to the immutable corpus revision evaluated. Have labels independently reviewed before using this set as a release gate.
