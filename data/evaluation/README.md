# Evaluation QA Set

`qa_set.json` contains a draft 18-case set tied to the NASA/TM-2004-213048 PDF in `data/curated/corpus/`. Its source corpus version is the document SHA-256 recorded in the corpus manifest. The labels are not independently reviewed; therefore the draft is useful for local test development but is not a release gate and its metrics must not be presented as reviewed benchmark results.

Each case must have a stable `id`, a specific `question`, `answerable`, and a source-grounded `reference_answer`. Answerable cases require one or more `relevant_source_ids` resolving to the exact stable identifiers used by retrieval. Unanswerable cases must use an explicit abstention reference and an empty source-ID list. `evaluate_dataset` applies RAGAS answer-quality metrics only to answerable cases; it separately reports retrieval-empty and explicit-abstention rates for out-of-corpus cases. Increment `dataset_version` when labels change and set `source_corpus_version` to the immutable corpus revision evaluated. Change `label_review_status` to `reviewed` only after an independent reviewer has checked every reference answer and relevant source page. Run `python scripts/validate_qa_dataset.py` to validate corpus checksums, cited pages, case counts, and unanswerable coverage.
